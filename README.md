📊 Project Overview

The Blinkit Business Analytics Dashboard is an interactive business intelligence project developed using Power BI to analyze sales, outlet performance, item categories, ratings, and other operational metrics.

The dashboard transforms raw Blinkit-style retail data into meaningful visual insights that can help understand sales performance, outlet trends, product distribution, and business operations.

This project demonstrates practical skills in data analysis, data visualization, dashboard development, business intelligence, and insight generation.

🎯 Project Objective

The main objective of this project is to:

Analyze overall sales performance.

Understand outlet-level sales and performance.

Identify sales distribution across item types.

Compare outlet sizes and outlet locations.

Analyze the relationship between item visibility, ratings, and sales.

Identify operational trends using interactive Power BI visualizations.

Present business insights in an easy-to-understand dashboard.

Power BI – Interactive dashboard development and visualization

📈 Key Insights

Based on the dashboard:

The business generated approximately $1.20M in total sales.

The average sales value is approximately $141.

The dataset contains 8,523 items.

The average customer/item rating is approximately 3.9.

Supermarket Type 1 contributes the highest sales among the displayed outlet types.

Tier 3 outlets show the highest sales among the displayed outlet location tiers.

The dashboard shows differences in sales performance between Low Fat and Regular Fat products.

Fruits and Vegetables and Snack Foods are among the highest-sales item categories displayed.

Outlet size and location can be compared interactively to understand sales distribution.

The dashboard makes it easier for decision-makers to identify operational trends and areas requiring attention.
